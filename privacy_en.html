Clopass Privacy Policy

Effective Date: July 11, 2026
Last Updated: August 9, 2026

Banakai (the “Operator”) establishes this Privacy Policy (the “Policy”) to explain how information is handled in connection with the Clopass mobile application (the “App”).

This Policy applies from the date version 2.0.0 of the App becomes available.

1. Our Approach to Privacy

The App is designed as a local-first application, with data primarily stored on the user’s device.

During normal use—including viewing, creating, and editing notes, studying with cloze exercises, and taking tests—the App does not transmit note content or study data to the Operator’s cloud services.

The App does not collect user data for advertising, behavioral tracking, analytics, or marketing purposes.

2. Information We Handle

2.1 Information Stored on the Device

The App stores the following information on the user’s device:

  • Folder and note titles
  • Note content, paragraphs, and cloze information
  • Study history, review history, and test history
  • Review schedules and study activity
  • Reminders and other app settings
  • App usage dates and launch history
  • The last note opened, reading position within the note, visibility state of cloze answers, partially revealed hints, Hint Mode status, and the date and time the note was last viewed

This information is stored on the user’s device. Except when the user chooses to use a cloud feature, the App does not transmit this information to the Operator’s cloud services.

2.2 Information Handled by Cloud Features

The App handles data required to provide a cloud feature only when the user uses automatic backup, manual backup, data restoration, or note sharing.

When a cloud feature is used for the first time, an anonymous internal identifier may be created as necessary to provide that feature. Users are not required to register a name, email address, or other account information.

When cloud features are used, external service providers may process the internal identifier, communication date and time, IP address, and other communication or security-related information.

2.3 Information Provided Through Inquiries

If a user contacts the Operator by email, the Operator will handle the user’s email address, inquiry details, and any other information necessary to respond.

3. How Data Is Handled by Each Feature

3.1 Backup and Data Restoration

When the user enables automatic backup or performs a manual backup, the App compresses and encrypts the data on the device before storing it in the cloud.

Note content and study data are not stored in the cloud in an unencrypted form.

Recovery codes and other information required to restore data are generated on the device and are not transmitted to the same cloud service that stores the encrypted backup.

Disabling automatic backup stops future automatic backups. However, backups that have already been created may remain stored until the user deletes them.

3.2 Recovery Codes and iCloud Keychain

Recovery codes and other recovery information are used by the user to restore data.

When available, the App may store only the information required for recovery in Apple’s iCloud Keychain.

Note content, study history, and test history are not stored directly in iCloud Keychain.

3.3 Note Sharing

When the user creates a sharing link, the App encrypts the shared note’s title, content, paragraphs, cloze information, and related data on the device before storing them in the cloud.

Study history, review history, test history, app settings, and similar information are not shared.

A sharing link allows anyone who has the link to duplicate and import the shared note. Do not post a sharing link in a place where unintended third parties may access it.

Edits made to a note after its sharing link has been created are not reflected in the existing shared copy. To share the latest version, create a new sharing link. Creating a new link invalidates the previous link.

3.4 Resume From the Last Viewed Note

To allow users to continue reading from where they left off, the App stores the last note opened, the reading position within the note, the visibility state of cloze answers, partially revealed hints, Hint Mode status, and the date and time the note was last viewed.

This information is overwritten with the latest viewing state and is not added or accumulated each time the note is viewed.

This resume information is not included in the App’s encrypted backups or note-sharing data and is not transmitted to the Operator’s cloud services.

3.5 Migration from Earlier Versions

For users updating from an earlier version of the App, the App may retrieve and convert previously stored data only to the extent necessary to migrate that data to the current version.

The retrieved data is migrated to the on-device database and is not used for any purpose other than migration.

4. Third-Party Services

When the user chooses to use cloud features, the App uses the following third-party services only as necessary to provide those features:

  • Supabase: Storage of identifiers used for cloud features, encrypted backups, and encrypted shared data
  • Cloudflare Turnstile: Prevention of misuse of cloud features and security verification
  • Apple iCloud Keychain: Storage and cross-device availability of information required for data recovery

These services may process information outside Japan. Information handled by each service is also subject to that service provider’s terms of service and privacy policy.

The Operator does not sell user data or disclose it to third parties for advertising purposes beyond what is necessary to provide the cloud features described in this Policy.

5. Purposes of Use

The Operator handles information only for the following purposes:

  • Providing the App and the cloud features selected by the user
  • Backing up and restoring data, and sharing notes
  • Restoring the viewing state of the last note opened
  • Preventing misuse and maintaining security
  • Investigating technical issues and responding to inquiries
  • Complying with applicable legal obligations

6. Data Retention and Deletion

Data stored on the device remains there until the user deletes it within the App or removes the App from the device.

Encrypted cloud backups, shared data, and identifiers used for cloud features are retained for as long as necessary to provide the relevant feature or until the user deletes them.

Using the App’s “Delete All Data” feature deletes data stored on the device and related data stored in the cloud. Due to processing requirements, it may take a reasonable amount of time for deletion from the cloud to be fully reflected.

If the user has not used any cloud features and no related cloud data exists, only the data stored on the device will be subject to deletion.

Uninstalling the App alone may not automatically delete data that has already been stored in the cloud.

As a general rule, users should delete their data through the App’s “Delete All Data” feature. If you have questions about deleting data or how your data is handled, please contact us using the information at the end of this Policy. We may be unable to fulfill a deletion request if we cannot verify the requester or identify the relevant data.

7. Disclosure to Third Parties

The Operator does not disclose user information to third parties except in the following circumstances:

  • When the user has given consent
  • When processing is entrusted to a third-party service described in this Policy to the extent necessary to provide the relevant feature
  • When disclosure is required by law
  • When disclosure is necessary to protect a person’s life, physical safety, or property, and obtaining the user’s consent is difficult

8. Security

The Operator takes reasonable administrative and technical measures to protect the information it handles against unauthorized access, disclosure, loss, destruction, or alteration.

However, the Operator cannot guarantee the complete security of communications or data storage. If an incident occurs, the Operator will take the actions required under applicable law.

9. Children’s Privacy

The App is not specifically designed for children under the age of 13, or any higher minimum age required by applicable law in the user’s jurisdiction.

The App does not require users to register their name or email address. If a child uses the App, a parent or legal guardian should supervise its use where required by applicable law.

If you believe that a child has provided personal information to the Operator through an inquiry or by other means, please contact us using the information below.

10. Changes to This Policy

The Operator may update this Policy in response to changes in the App’s features, applicable laws, or other circumstances.

Any updated version of this Policy will be made available on this page.
